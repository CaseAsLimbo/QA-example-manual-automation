## Проверки безопасности и валидации страницы корзины товаров
>[!IMPORTANT]
> build: 1.3.4.5\
> Дата проверки: 22.06.2026\
> Окружение: Linux Ubuntu 22.04, Firefox\
> Проверяющий: Намазов Максим

> [!Note]
> Тестирование проводится для разлогиненного пользователя

| № | Проверка | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Использование HTTPS | Все ресурсы и API-запросы выполняются по протоколу HTTPS (проверить в DevTools) |
| 2 | Наличие CSRF-токенов в критичных запросах (добавление, удаление, изменение количества) | В заголовках или теле запросов присутствует токен, сервер отклоняет запрос без токена (403) |
| 3 | Валидация количества на серверной стороне | Изменение количества через прямой API-запрос с невалидными данными (отрицательное, 0, 1e5) возвращает ошибку 400 без изменения корзины |
| 4 | Защита от XSS в поле количества | Ввод `<script>alert(1)</script>` в поле количества не приводит к выполнению скрипта (отображается как текст или игнорируется) |
| 5 | Обработка спецсимволов в поле адреса на карте | Спецсимволы (`'`, `"`, `<`, `>`) не ломают интерфейс и корректно передаются/экранируются |
| 6 | Проверка cookie сессии после добавления товаров | Сессионные cookie имеют флаги `Secure`, `HttpOnly`, `SameSite=Lax` (или Strict). Конфиденциальные данные не видны в `document.cookie` |
| 7 | Отсутствие передачи конфиденциальной информации в URL | Адрес, выбранный на карте, не отображается в строке браузера (передаётся через POST/PUT) |
| 8 | Обработка истечения сессии при длительном бездействии | Если сессия истекла, попытка изменить количество или оформить заказ показывает сообщение "Сессия истекла, обновите страницу" |
| 9 | Безопасность кнопки "Поделиться" | Генерируемая ссылка не содержит приватных данных пользователя (только публичную информацию о товарах) |
| 10 | Валидация на сервере при добавлении товара с истёкшим/некорректным идентификатором | Запрос на добавление несуществующего товара возвращает ошибку, товар не появляется в корзине |
