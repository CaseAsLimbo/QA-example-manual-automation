### Проверки UI / UX <br>[TC-OZON-CART-UI_UX-001](https://github.com/CaseAsLimbo/QA-example-manual-automation/blob/7ada665974a634cc6794e11144d9aecfa1d7deb1/manual/test-cases/TC-OZON-CART-UI_UX-001.md)
>[!IMPORTANT]
> build: 1.3.4.5\
> Дата проверки: 20.06.2026\
> Окружение: Linux Ubuntu 22.04, Firefox\
> Проверяющий: Намазов Максим

> [!Note]
> Тестирование проводится для разлогиненного пользователя

| № | Проверка | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Соответствие внешнего вида пустой корзины макету | Заголовок, текст, кнопка "Войти" и блок "Рекомендуем" отображаются согласно дизайну (шрифты, отступы, цвета) |
| 2 | Карточка товара в "Рекомендуем": обрезание названия на 58 символах | Название длиной ≤58 символов отображается полностью. Название длиной 59+ символов обрезается и заканчивается многоточием "…" |
| 3 | Отображение цены в карточке | Реальная цена – крупный красный текст; старая цена – серое перечёркнутое изображение; скидка в формате "‑82%" – красный текст |
| 4 | Кнопка "В корзину" в двух состояниях | Синяя кнопка – стандартный цвет; красная кнопка – для товаров с экспресс-доставкой. На кнопке с короной отображается значок короны для хитов |
| 5 | Адаптивность страницы (планшет 768px, мобильное 375px) | Элементы корзины и карточек не вылезают за экран, перестраиваются в одну колонку, кнопки и текст читаемы |
| 6 | Состояния кнопок (hover, active, focus) | Все кликабельные элементы реагируют на наведение (изменение фона/тени), имеют видимый фокус при табуляции |
| 7 | Переключатель количества: визуальное отображение | Кнопки "+" и "‑" имеют узнаваемый вид, поле ввода показывает текущее количество. При наведении курсор меняется на pointer |
| 8 | Чекбокс "Выбрать всё" и чекбоксы товаров: состояния (отмечен/не отмечен, mixed при части выбранных) | При выборе всех вручную чекбокс "Выбрать всё" автоматически отмечается. При снятии одного – снимается "Выбрать всё". Визуальные стили соответствуют гайдлайнам |
| 9 | Кнопка "Лайк" (сердце) в карточке и строке товара | Пустое сердце сменяется закрашенным при добавлении в избранное. При повторном нажатии возвращается к пустому. Анимация может присутствовать |
| 10 | Всплывающее окно "Куда доставить заказ?" | Окно появляется плавно, содержит описанные элементы, не выходит за границы экрана. Закрывается по крестику или клику вне области |
| 11 | Интерактивная карта | Карта загружается без ошибок, маркер можно перетаскивать, элементы управления (+/-/геолокация) работают. Поле ввода адреса реагирует на ввод |
| 12 | Правый блок с итогами | Чётко отображается итоговая цена, количество товаров, вес (г), скидка, способы оплаты. Данные обновляются без задержки при изменении состава корзины |
| 13 | Кнопка "Перейти к оформлению" доступна и контрастна | Кнопка выделяется на фоне, текст читается, при наведении есть визуальная обратная связь |
| 14 | Сообщения об ошибках валидации (при некорректном количестве) | Появляются рядом с полем, красный текст/иконка, исчезают после исправления |
| 15 | Обновление блока "Перейти к оформлению" при добавлении товаров | Пока идет перерасчет, в окне отображается анимация загрузки(синий круг). Анимация не снимается, пока между добавлениями товаров(Нажатии на кнопки "+" или "В корзину") не прошло более 1 секунды |
| 16 | Перезагрузка страницы корзины | Каждый блок на странце заменяется на скелетон с анимацией загрузки(черный круг). Время загрузки каждого блока не превышает 0.25 секунды |
