## Login_form_Stack_Overflow_UI_UX_check-list
>[!IMPORTANT]
> build: 1.5.6.7\
> Дата проверки: 15.06.2026\
> Окружение: Linux Ubuntu 22.04, Firefox\
> Проверяющий: Намазов Максим

| №   | Проверка                                                                 | Результат:                                                                                                                                                     |
| --- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Внешний вид формы на десктопных разрешениях (1920, 1366, 1024 px)        | Форма центрирована, логотип вверху, кнопки соцсетей расположены согласно макету, поля и кнопка "Войти" выровнены, нет обрезаний                                |
| 2   | Отображение на планшетах (768 px) и мобильных (375 px)                   | Форма адаптивна: кнопки соцсетей переносятся, ширина полей не выходит за экран, логотип уменьшается пропорционально                                            |
| 3   | Табуляция по элементам (Tab / Shift+Tab)                                 | Порядок фокуса логичный: Почта → Пароль → (глазик) → Войти → ссылки "Забыли пароль?", "Зарегистрируйтесь" → кнопки соцсетей. Фокус визуально заметен (outline) |
| 4   | Нажатие Enter в поле "Почта"                                             | Фокус перемещается на поле "Пароль"                                                                                                                            |
| 5   | Нажатие Enter в поле "Пароль"                                            | Отправляется форма (эквивалентно клику "Войти")                                                                                                                |
| 6   | Состояния кнопки "Войти": default, hover, active, disabled               | Стили соответствуют бренду: при наведении меняется фон/тень, при нажатии – эффект вдавливания, disabled – серый/блёклый                                        |
| 7   | Состояния ссылок "Забыли пароль?" и "Зарегистрируйтесь": hover, visited  | Цвет меняется в соответствии с общим стилем (например, синий/оранжевый), подчёркивание появляется при наведении                                                |
| 8   | Состояния кнопок соцсетей (hover, active)                                | Каждая кнопка имеет иконку и текст, при наведении выделяется (лёгкая анимация/затемнение)                                                                      |
| 9   | Сообщения об ошибках валидации: расположение, цвет, иконка               | Ошибка появляется под полем, текст красного цвета. Исчезает после исправления и расфокусировки                 |
| 10  | Переключатель видимости пароля: иконка "глаз" (открытый / перечёркнутый) | Иконка интуитивно понятна, при наведении курсор меняется на pointer, смена состояния анимирована (плавное переключение)                                        |
| 11  | Плейсхолдеры в полях                                                     | В поле "Почта" текст "Введите адрес электронной почты", в "Пароль" – "Введите пароль". При вводе плейсхолдер исчезает                                          |
| 12  | Локализация интерфейса (русский язык)                                    | Все надписи: "Войти", "Почта", "Пароль", "Забыли пароль?", "Ещё нет учётной записи? Зарегистрируйтесь" отображаются на русском                                 |
| 13  | Отображение логотипа Stack Overflow                                      | Логотип качественный (не размыт), кликабелен, курсор pointer при наведении                                                                                     |
| 14  | Скорость загрузки страницы                                               | Форма загружается без видимых задержек, элементы не прыгают (стили загружены до отрисовки)                                                                     |
| 15  | Проверка доступности (Accessibility) – контрастность, alt у иконок       | Текст читаем (контраст не ниже AA), иконки кнопок соцсетей и "глазик" имеют текстовые альтернативы / aria‑labels                                               |
| 17  | После перезагрузки страница полностью обновляется в исходный вид         | Не отображаются вызванные до перезагрузки сообщения об ошибке                                                                                                  |
