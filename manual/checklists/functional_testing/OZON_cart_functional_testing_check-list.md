# Проверка функциональности корзины товаров
>[!IMPORTANT]
> build: 1.3.4.5\
> Дата проверки: 20.06.2026\
> Окружение: Linux Ubuntu 22.04, Firefox\
> Проверяющий: Намазов Максим

> [!Note]
> Тестирование проводится для разлогиненного пользователя
## Позитивные проверки
### Общие(страница корзины https://www.ozon.ru/cart)
| № | Проверка | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Открытие пустой корзины (пользователь не авторизован) | Отображается заголовок "Корзина пуста", пояснительный текст и кнопка "Войти" |
| 2 | Нажатие кнопки "Войти" в пустой корзине | Открывается форма входа (модальное окно) |
| 3 | Загрузка блока "Рекомендуем" при пустой корзине | Отображается список карточек товаров. Каждая карточка содержит все необходимые элементы: изображение, цены, название, рейтинг, кнопку "В корзину", кнопку "Лайк" |
| 4 | Добавление товара с пометкой "Распродажа" | Под полем количества товара отображается сообщение "Количество ограничено" |
| 5 | Корзина с одним товаром: изменение количества через кнопку "+" | Количество увеличивается на 1. Общая цена, итоговая цена, вес, скидка в блоке "Перейти к оформлению" пересчитываются пропорционально |
| 6 | Изменение количества через кнопку "‑" (текущее > 1) | Количество уменьшается на 1. Общая цена, итоговая цена, вес, скидка в блоке "Перейти к оформлению" пересчитываются пропорционально |
| 7 | Изменение количества до 1 и нажатие "‑" | Всплывает pop-up "Удалить товар" с текстом "Вы точно хотите удалить выбранный товар? Отменить данное действие будет невозможно" |
| 8 | Ручной ввод в поле количества допустимого значения (например, 5) и нажатие Enter | Количество обновляется до указанного. Общая цена, итоговая цена, вес, скидка в блоке "Перейти к оформлению" пересчитываются пропорционально |
| 9 | Нажатие на кнопку мусорки из блока "Доступные товары" или блока фильтра | Товар исчезает из корзины. Счётчик обнуляется. При удалении единственного товара корзина возвращается к состоянию "Корзина пуста" с блоком "Рекомендуем" |
| 10 | Нажатие кнопки "Лайк" в строке товара в корзине | Товар добавляется в "Избранное" (иконка меняется), счетчик "Избранное" увеличивается на 1. Если уже в избранном – удаляется |
| 11 | Установка чекбокса "Выбрать всё" в блоке фильтра | Все чекбоксы отдельных товаров становятся отмеченными. Итоговая сумма, вес и скидка в блоке "Перейти к оформлению" обновляются для всех выбранных товаров |
| 12 | Снятие чекбокса "Выбрать всё" | Все товары снимаются с выделения. Итоговые значения обнуляются (цена 0, вес 0). Блок "Перейти к оформлению" становится серым, кнопка не "Перейти к оформлению" не кликабельна, внизу блока отображается сообщение "Выберите товары, чтобы перейти к оформлению заказа" |
| 13 | Выборочная установка чекбоксов у части товаров | "Выбрать всё" автоматически активируется, когда выбраны все товары вручную. Итоги пересчитываются для выделенных товаров |
| 14 | Нажатие кнопки "Поделиться" | Открывается диалог шаринга (соцсети, копирование ссылки) с информацией о товарах в корзине |
| 15 | Кнопка "Перейти к оформлению" при наличии товаров | Происходит переход на страницу оформления заказа (проверить корректный URL) |

## Негативные проверки
### Общие(страница корзины https://www.ozon.ru/cart)
| № | Проверка | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Ввод в поле количества товаров значения 0 | Поле не принимает 0 (сбрасывается на 1) |
| 2 | Ввод отрицательного числа (например, -1) | Блокируется ввод символов иных цифрам, например `+=-;:*(\?№AB.,` |
| 3 | Ввод дробного числа (например, 1.5) | Блокируется ввод символов иных цифрам, например `+=-;:*(\?№AB\.,` |
| 5 | Ввод в поле количества нечисловых символов (буквы, спецсимволы) | Блокируется ввод символов иных цифрам, например `+=-;:*(\?№AB\.,` |
| 4 | Ввод очень большого числа больше максимального для одного добавленного товара (граничное значение 2000 товаров в сумме на корзину) <br>[TC-OZON-CART-003](https://github.com/CaseAsLimbo/QA-example-manual-automation/blob/eaa23e200e64337bbc08a3bfc46dcdbb98cf8059/manual/test-cases/TC-OZON-CART-003.md) | Система обрезает число > 2000 товаров до 2000. При попытке добавить больше по нажатии на "+" всплывает Всплывашка с сообщением "2000 единиц — это максимум Удалите неактуальные товары, чтобы добавить новые" |
| 6 | Проверка огрнаичения полей ввода при добавлении нескольких товаров | При достижении общей суммы количества товаров в корзине 2000 добавление новых блокируется, всплывает Всплывашка с сообщением "2000 единиц — это максимум Удалите неактуальные товары, чтобы добавить новые". |
| 7 | Попытка добавить товар с пометкой "Распродажа"(ограниченное количество) сверх указанного количества(при том, что количество товара < 2000 единиц) | Кнопка "+" для добавления товара становится не активной при достижении максимального количества этого товара |
| 8 | Вставка текста из буфера обмена в поле количества | Если вставленный текст не является целым положительным числом, поле возвращает предыдущее корректное значение |
| 9 | Повторное добавление одного и того же товара (по синей кнопке) | Количество этого товара в корзине увеличивается на 1, а не создаётся дублирующая запись |
| 10 | Попытка добавления товара с красной кнопкой без указания адреса (закрытие окна "Куда доставить заказ?" по крестику или клику вне окна) | Окно закрывается, товар не добавляется в корзину. Счётчик не изменяется |
| 11 | Отправка запроса изменения количества при потере интернет-соединения (имитация через DevTools) | Появляется сообщение об ошибке сети, количество возвращается к предыдущему значению |
| 12 | Переход к оформлению без выбранных товаров (если снять все чекбоксы) | Кнопка "Перейти к оформлению" становится неактивной, не кликабельной|
