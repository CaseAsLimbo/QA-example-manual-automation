Тест-кейс 3 (Негативный / Превышение максимального количества)

- **Id:** TC-OZON-CART-003
- **Приоритет:** Medium
- **Ссылка на требование:** REQ-CART-003 (ограничение максимального количества товара в корзине)
- **Модуль:** Корзина -> Управление количеством -> Валидация максимального количества
- **Заголовок:** Обрезание значения поля количества до 2000 при ручном вводе числа, превышающего лимит
- **Описание:** Проверка, что при вводе в поле количества значения больше 2000 система автоматически корректирует его до 2000 и выводит соответствующее уведомление.
- **Предусловия:**
  - Открыта страница корзины https://www.ozon.ru/cart.
  - В корзине находится один товар с текущим количеством = 1 (любой товар).
- **Шаги:**
  1. В строке товара кликнуть в поле ввода количества (где отображается "1"), стереть текущее значение и ввести "2500", нажать Enter
     - Ожидаемый результат: Значение в поле автоматически заменяется на "2000". В виде всплывающего сообщения появляется уведомление "2000 единиц — это максимум. Удалите неактуальные товары, чтобы добавить новые".
  2. Проверить пересчёт итогов в правом блоке
     - Ожидаемый результат: Итоговая цена, вес и скидка пересчитываются исходя из количества 2000. Кнопка "Перейти к оформлению" активна.
- **Постусловия:** Вернуть количество товара к исходному (например, изменить на 1 или удалить товар).
- **Вложения:** Скриншоты: поле количества до и после ввода, всплывающее сообщение.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (build 1.3.4.5)
- **Дополнительная информация:** Лимит 2000 распространяется на общее количество единиц в корзине; данный кейс проверяет поведение для одного товара. При попытке добавить другой товар сверх лимита также должно появляться сообщение.
