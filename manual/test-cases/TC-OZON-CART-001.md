### Тест-кейс 1 (Позитивный / Указание адреса)

- **Id:** TC-OZON-CART-001
- **Приоритет:** High
- **Ссылка на требование:** REQ-CART-001 (добавление товара с экспресс-доставкой и указанием адреса)
- **Модуль:** Корзина -> Добавление товара -> Указание адреса
- **Заголовок:** Добавление товара с экспресс-доставкой в корзину с указанием адреса через карту
- **Описание:** Проверка полного сценария добавления товара, отмеченного короной и красной кнопкой, с последующим выбором адреса через текстовый ввод и карту.
- **Предусловия:**
  - Браузер в стандартном режиме (куки и JavaScript включены).
  - Пользователь не авторизован.
  - Открыта страница корзины https://www.ozon.ru/cart (пустая корзина).
  - На странице присутствует блок "Рекомендуем" с карточками товаров. Найден товар с красной кнопкой "В корзину" (иконка короны, экспресс-доставка за 30 минут).
- **Шаги:**
  1. Нажать красную кнопку "В корзину" на карточке выбранного товара
     - Ожидаемый результат: Появляется модальное окно "Куда доставить заказ?" с текстом и ссылкой о зонах доставки.
  2. В окне "Куда доставить заказ?" нажать кнопку "Указать Адрес"
     - Ожидаемый результат: Открывается окно с интерактивной картой, полем ввода "Адрес" и элементами управления (+/-/геолокация).
  3. В текстовое поле "Адрес" ввести реальный обслуживаемый адрес (например, "Москва, Тверская улица, 7") и нажать Enter
     - Ожидаемый результат: Карта центрируется по введённому адресу, маркер устанавливается в соответствующую точку, кнопка "Привезти сюда" становится активной.
  4. Нажать кнопку "Привезти сюда"
     - Ожидаемый результат: Окно карты закрывается, окно "Куда доставить заказ?" также исчезает. Товар добавляется в корзину: появляется счётчик товаров рядом с заголовком "Корзина", отображаются блоки "Выбрать всё", "Поделиться", "Удалить все", а также блок "Доступные товары" с информацией о товаре и правый блок с итогами. При наличии метки экспресс-доставки она сохраняется.
- **Постусловия:** Удалить добавленный товар из корзины (нажать на мусорку в строке товара или на кнопку "-" -> в появившемя pop-up-е нажать на кнопку "Удалить") для возврата к исходному состоянию.
- **Вложения:** Скриншоты: карта с введённым адресом и активной кнопкой "Привезти сюда"; корзина с добавленным товаром.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (build 1.3.4.5)
- **Дополнительная информация:** Для теста использован публичный адрес, доступный для экспресс-доставки Ozon.
