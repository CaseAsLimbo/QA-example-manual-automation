- **Id:** TC-Stack_Overflow-LOGIN-002
- **Приоритет:** High
- **Ссылка на требование:** REQ-LOGIN-002 (авторизация через OAuth-провайдера GitHub)
- **Модуль:** Авторизация > Форма входа > OAuth
- **Заголовок:** Успешная авторизация через кнопку «Войти через GitHub»
- **Описание:** Проверка входа с использованием существующей привязки GitHub-аккаунта.
- **Предусловия:**
  - Учётная запись Stack Overflow связана с действующим GitHub-аккаунтом `testgithubuser`.
  - Пользователь не авторизован на сайте.
  - Открыта страница входа (URL как в TC-LOGIN-001).
- **Шаги:**
  1. Нажать кнопку «Войти через GitHub»
     - Ожидаемый результат: Происходит перенаправление на страницу авторизации GitHub (https://github.com/login/oauth/authorize).
  2. На странице GitHub подтвердить предоставление доступа (Authorize)
     - Ожидаемый результат: После согласия браузер возвращается на ru.stackoverflow.com.
  3. Дождаться завершения редиректа
     - Ожидаемый результат: Пользователь автоматически авторизован, отображается главная страница с данными учётной записи.
- **Постусловия:** Выйти из системы. При необходимости отозвать доступ приложения в настройках GitHub.
- **Вложения:** Скриншот экрана согласия GitHub и результирующей страницы.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (сборка 1.3.4.5)
- **Дополнительная информация:** Для повторения теста требуется реальная привязка GitHub к аккаунту.
