### Тест-кейс 2 (Позитивный / Удаление товара через pop-up)

- **Id:** TC-OZON-CART-002
- **Приоритет:** Medium
- **Ссылка на требование:** REQ-CART-002 (удаление товара из корзины с подтверждением через pop-up)
- **Модуль:** Корзина -> Управление количеством -> Удаление товара
- **Заголовок:** Подтверждение удаления товара через pop-up при уменьшении количества до 0
- **Описание:** Проверка, что при попытке уменьшить количество единственного товара до нуля появляется pop-up с запросом подтверждения, и после подтверждения товар удаляется.
- **Предусловия:**
  - Открыта страница корзины https://www.ozon.ru/cart.
  - В корзине присутствует ровно один товар с количеством = 1 (добавлен любым способом, например, через синюю кнопку в блоке "Рекомендуем").
- **Шаги:**
  1. В блоке "Доступные товары" для данного товара нажать кнопку "‑" (уменьшить количество)
     - Ожидаемый результат: Всплывает pop-up окно с текстом "Вы точно хотите удалить выбранный товар? Отменить данное действие будет невозможно" и кнопками "Удалить" и закрытия (крестик).
  2. В pop-up окне нажать кнопку "Удалить"
     - Ожидаемый результат: Pop-up закрывается. Товар полностью удаляется из корзины. Счётчик товаров рядом с заголовком "Корзина" обнуляется, страница возвращается к состоянию "Корзина пуста" с отображением блока "Рекомендуем".
- **Постусловия:** Не требуются (корзина пуста).
- **Вложения:** Скриншоты: pop-up окно перед нажатием; пустая корзина после удаления.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (build 1.3.4.5)
- **Дополнительная информация:** Альтернативный способ вызова pop-up (кнопка мусорки) даёт аналогичный результат, но в данном кейсе проверяется именно сценарий с кнопкой "‑".
