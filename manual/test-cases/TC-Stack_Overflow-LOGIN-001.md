- **Id:** TC-Stack_Overflow-LOGIN-001
- **Приоритет:** High
- **Ссылка на требование:** REQ-LOGIN-001 (успешная аутентификация по email и паролю)
- **Модуль:** Авторизация > Форма входа
- **Заголовок:** Успешный вход с корректными email и паролем существующего аккаунта
- **Описание:** Проверка базового сценария входа зарегистрированного пользователя с верными учётными данными.
- **Предусловия:**
  - Учётная запись `testuser@example.com` с паролем `ValidP@ss1` зарегистрирована и подтверждена.
  - Открыта страница входа: https://ru.stackoverflow.com/users/login?ssrc=head&returnurl=https%3a%2f%2fru.stackoverflow.com%2f
- **Шаги:**
  1. В поле «Почта» ввести `testuser@example.com`
     - Ожидаемый результат: Поле заполняется, валидация не выдаёт ошибок.
  2. В поле «Пароль» ввести `ValidP@ss1`
     - Ожидаемый результат: Символы скрыты (точки/звёздочки), ошибок нет.
  3. Нажать кнопку «Войти»
     - Ожидаемый результат: Происходит перенаправление на главную страницу `https://ru.stackoverflow.com`. В шапке сайта отображаются аватар и репутация пользователя.
- **Постусловия:** Выйти из аккаунта (нажать «Выйти» в меню профиля).
- **Вложения:** Скриншот главной страницы после успешного входа.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (сборка проверки 1.3.4.5)
- **Дополнительная информация:** Тестовые данные действительны для тестового окружения.
