- **Id:** TC-Stack_Overflow-LOGIN-005
- **Приоритет:** Low
- **Ссылка на требование:** REQ-LOGIN-005 (работа буфера обмена со спецсимволами)
- **Модуль:** Авторизация > Форма входа > Поле «Пароль»
- **Заголовок:** Копирование и вставка пароля, содержащего спецсимволы, из буфера обмена
- **Описание:** Проверка, что пароль со специальными символами корректно вставляется и не искажается при последующей отправке.
- **Предусловия:**
  - Существует аккаунт с паролем `T!e@s#t$P%a^s&s*()`
  - Открыта страница входа.
- **Шаги:**
  1. Скопировать в буфер обмена строку `T!e@s#t$P%a^s&s*()`
  2. В поле «Почта» ввести email, соответствующий аккаунту с этим паролем
     - Ожидаемый результат: Поле заполнено.
  3. В поле «Пароль» вставить содержимое буфера обмена (Ctrl+V или через контекстное меню)
     - Ожидаемый результат: Все символы, включая `!@#$%^&*()`, вставляются без искажений. Поле отображает скрытые символы.
  4. Нажать кнопку «Войти»
     - Ожидаемый результат: Успешная аутентификация, переход на главную страницу.
- **Постусловия:** Выйти из системы.
- **Вложения:** Скриншот поля пароля с включённым просмотром (если необходимо).
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (сборка 1.3.4.5)
- **Дополнительная информация:** Спецсимволы соответствуют часто используемым в паролях. Убедиться, что менеджер паролей не интерферирует.
