### Тест-кейс TC-Stack_Overflow-SECURITY-LOGIN-001 (XSS и SQL-инъекции)
- **Id:** TC-Stack_Overflow-SECURITY-LOGIN-001
- **Приоритет:** High
- **Ссылка на требование:** REQ-SEC-001 (защита от внедрения вредоносного кода)
- **Модуль:** Авторизация -> Форма входа -> Безопасность ввода
- **Заголовок:** Проверка устойчивости полей ввода к XSS и SQL-инъекциям
- **Описание:** Проверяется, что форма логина корректно экранирует или отклоняет вредоносные строки, не допуская выполнения скриптов и обхода аутентификации через SQL-инъекции.
- **Предусловия:**
  - Открыта страница входа: https://ru.stackoverflow.com/users/login?ssrc=head&returnurl=https%3a%2f%2fru.stackoverflow.com%2f
  - Браузер Firefox в стандартном режиме (куки и JavaScript включены).
  - Перед проведением теста посоветоваться/предупредить отдел ИБ
  - Тестовые данные:
    - SQL-инъекция: `' OR '1'='1`
    - XSS-вектор: `<script>alert('XSS')</script>`
- **Шаги:**
  1. В поле "Почта" ввести `' OR '1'='1`, в поле "Пароль" ввести любой текст (например, `test`). Нажать кнопку "Войти".
     - Ожидаемый результат: Аутентификация не проходит. Система возвращает обобщённое сообщение "Почта или пароль заданы неверно." без признаков ошибки базы данных. Приложение не прерывает работу, не отображает внутренних сообщений.
  2. В поле "Почта" ввести `<script>alert('XSS')</script>`, в поле "Пароль" ввести любой текст (например, `test`). Нажать "Войти".
     - Ожидаемый результат: Появляется сообщение об ошибке аутентификации. Введённый скрипт не выполняется (всплывающее окно с `alert` не появляется). Строка отображается как обычный текст в поле или в сообщении об ошибке без интерпретации браузером.
  3. Повторить шаги 1 и 2 для поля "Пароль", используя аналогичные вредоносные строки в нём, а в поле "Почта" — валидный email.
     - Ожидаемый результат: Результат полностью аналогичен — инъекции не проходят, скрипты не выполняются, сообщение об ошибке универсальное.
- **Постусловия:** Не требуются.
- **Вложения:** Скриншоты сообщений об ошибках без следов выполнения скриптов; консоль браузера без ошибок, связанных с XSS.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (build 1.5.6.7)
- **Дополнительная информация:** Проверка показывает, что приложение следует принципам безопасного кодирования: данные экранируются, фильтруются или параметризуются запросы.
