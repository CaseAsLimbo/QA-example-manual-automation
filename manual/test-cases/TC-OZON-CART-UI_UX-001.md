### Тест-кейс TC-OZON-CART-UI_UX-001

- **Id:** TC-OZON-CART-UI_UX-001
- **Приоритет:** Medium
- **Ссылка на требование:** REQ-UI-001 (визуальное отображение и интерактивность элементов корзины с товарами)
- **Модуль:** Корзина -> UI/UX
- **Заголовок:** Проверка визуального отображения и поведения основных интерактивных элементов корзины при наличии товара
- **Описание:** Комплексная проверка UI-элементов корзины: внешний вид и поведение переключателя количества, чекбоксов выбора, правого блока с итогами, кнопки "Перейти к оформлению", анимации загрузки при пересчёте.
- **Предусловия:**
  - Браузер Firefox, окно в десктопном разрешении (1920×1080).
  - Пользователь не авторизован.
  - Открыта страница корзины https://www.ozon.ru/cart.
  - В корзину добавлен ровно один товар (например, через синюю кнопку в блоке "Рекомендуем").
- **Шаги:**
  1. Обратить внимание на внешний вид переключателя количества в строке товара (кнопки "+", "‑" и поле ввода)
     - Ожидаемый результат: Кнопки "+" и "‑" имеют узнаваемую форму, на них отображаются соответствующие символы. Поле ввода показывает текущее количество (1). При наведении курсора на кнопки он меняется на pointer. Кнопки и поле визуально согласованы.
  2. Нажать кнопку "+" один раз
     - Ожидаемый результат: Количество меняется на 2. В правом блоке "Перейти к оформлению" в момент пересчёта кратковременно отображается анимация загрузки (синий вращающийся круг), которая исчезает после завершения пересчёта (если между последовательными нажатиями прошло более 1 секунды). Итоговая цена, количество и вес обновляются корректно (удваиваются). Скидка пересчитывается пропорционально.
  3. В правом блоке "Перейти к оформлению" проверить чёткость отображения итоговой информации
     - Ожидаемый результат: Блок содержит итоговую цену (крупно), количество товаров, общий вес (в граммах), итоговую скидку и способы оплаты. Все числа отформатированы, текст читаем, нет обрезаний.
  4. Проверить состояние чекбокса "Выбрать всё" над списком товаров
     - Ожидаемый результат: Чекбокс отмечен (так как товаров два и они выбраны). Чекбокс имеет стандартный вид (отмеченная галочка).
  5. Снять отметку с чекбокса товара в блоке "Доступные товары"
     - Ожидаемый результат: Чекбокс товара становится пустым. Чекбокс "Выбрать всё" также автоматически снимается. Кнопка "Перейти к оформлению" в правом блоке становится серой (неактивной), внизу блока появляется сообщение "Выберите товары, чтобы перейти к оформлению заказа". Итоговые значения исчезают(в окне "Перейти к оформлению остается только сообщение о необходимости выбора товаров.)
  6. Снова отметить чекбокс товара
     - Ожидаемый результат: Чекбокс "Выбрать всё" автоматически отмечается. Кнопка "Перейти к оформлению" снова становится активной, контрастной, появляется визуальная обратная связь (hover-эффект) при наведении курсора. Итоговые данные восстанавливаются до актуальных значений.
  7. Проверить состояние фокуса и hover на кнопках "+", "‑", чекбоксах и кнопке "Перейти к оформлению" с помощью Tab и наведения мыши
     - Ожидаемый результат: При нажатии Tab фокус последовательно перемещается по элементам: чекбокс, кнопка "Лайк", название товара, "+", поле ввода, "‑", кнопка удаления, чекбокс "Выбрать всё", кнопка "Поделиться", кнопка "Удалить все", кнопка "Перейти к оформлению". Каждый элемент в фокусе имеет видимый outline. При наведении мыши на кнопки меняется фон/тень (hover-эффект).
- **Постусловия:** Удалить товары из корзины (нажать на мусорку в блоке фильтров с включенным чекбоксом "Выбрать всё"), чтобы вернуться к состоянию пустой корзине.
- **Вложения:** Скриншоты: правый блок с итогами до и после увеличения количества; неактивная кнопка "Перейти к оформлению" при снятом чекбоксе; элемент в фокусе с outline.
- **Окружение:** Linux Ubuntu 22.04, Firefox 130.0 (build 1.3.4.5)
- **Дополнительная информация:** Анимация загрузки (синий круг) может быть трудноуловима визуально; для её проверки допускается замедление соединения через DevTools.
